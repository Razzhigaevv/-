КАК ВЫЛОЖИТЬ САЙТ НА GITHUB — ПОШАГОВО (для новичка)
=====================================================

ЧАСТЬ 1. ЗАГРУЗКА ФАЙЛОВ
-------------------------
1. Зайдите на github.com и войдите в аккаунт
   (если аккаунта нет — «Sign up», регистрация бесплатная).

2. Нажмите «+» в правом верхнем углу → «New repository».

3. Заполните:
   - Repository name:  osobiy-dosug
   - Выберите «Public» (нужно для бесплатного сайта)
   - Галочку «Add a README» ставить НЕ нужно
   Нажмите зелёную кнопку «Create repository».

4. На открывшейся странице нажмите ссылку
   «uploading an existing file»
   (или кнопку «Add file» → «Upload files»).

5. Откройте распакованную папку osobiy-dosug,
   выделите ВСЁ внутри неё (Ctrl+A) и ПЕРЕТАЩИТЕ файлы мышкой в окно браузера.

   ⚠️ ВАЖНО: перетаскивайте ФАЙЛЫ ИЗНУТРИ папки, а не саму папку!
   Файл index.html должен оказаться прямо в корне репозитория.
   (Перетаскивать папку целиком тоже можно — файлы лягут правильно,
   но проверьте, что index.html не оказался внутри вложенной папки.)

6. Дождитесь, пока все файлы загрузятся, и нажмите
   зелёную кнопку «Commit changes».

ЧАСТЬ 2. ВКЛЮЧЕНИЕ САЙТА (бесплатный хостинг GitHub Pages)
-----------------------------------------------------------
7. В репозитории откройте вкладку «Settings» (вверху).

8. В меню слева найдите раздел «Pages».

9. В блоке «Build and deployment»:
   - Source:            Deploy from a branch
   - Branch:            main
   - Folder:            / (root)
   Нажмите «Save».

10. Подождите 1–2 минуты и обновите страницу — сверху появится ссылка:
    https://ВАШ_ЛОГИН.github.io/osobiy-dosug/
    Это и есть ваш сайт — можно отправлять ссылку кому угодно 🎉

ЕСЛИ ЧТО-ТО НЕ ПОЛУЧИЛОСЬ
--------------------------
- Сайт показывает 404 → проверьте, что index.html лежит в КОРНЕ
  репозитория и что в Pages выбрана папка / (root).
- Ссылка не появляется → подождите ещё пару минут и обновите страницу.
- Изменить файлы потом → «Add file» → «Upload files» → загрузите
  новые версии тех же файлов → «Commit changes».

Альтернатива: можно установить приложение GitHub Desktop —
оно умеет загружать папку целиком одним движением.
