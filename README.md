# 🧩 Особый досуг

Демо сайта-подбора развивающих игр для детей с учётом возраста и особенностей развития.
Сайт полностью статический — не требует сервера, базы данных и установки чего-либо.

## Что умеет

- 🧩 **944 игры** — у каждой указан возраст и список вещей, которые понадобятся
- 🎯 **Только подходящие** — список фильтруется по возрасту и особенностям ребёнка
- 🃏 **Карточки-подсказки** — только у игр, где нужны карточки (лото, пары, эмоции…)
- 💬 **Чат** — напишите, какие вещи есть дома, и игра придумается из них
- 🎨 **Творчество** — сказка с выбором длительности и озвучкой + аватарка со скачиванием
- 🦸 **Супер-герой** — особенности ребёнка превращаются в суперсилы
- 👤 **Личный кабинет** — профиль «под фоткой», Мои игры ❤️, дневник, отчёт для специалиста

## 🌐 Как открыть сайт онлайн (GitHub Pages)

1. Откройте свой репозиторий → **Settings** → раздел **Pages**
2. Source: **Deploy from a branch**
3. Branch: **main** · Folder: **/ (root)** → **Save**
4. Через 1–2 минуты сайт будет доступен по адресу:
   `https://ВАШ_ЛОГИН.github.io/osobiy-dosug/`

Подробная инструкция для новичка — в файле **ИНСТРУКЦИЯ.txt**.

## 💻 Как запустить локально

Просто откройте файл `index.html` двойным кликом — сайт работает без интернета
(нужен только для красивого шрифта).

## 📁 Структура проекта

```
index.html          — страница сайта (вся вёрстка и стили)
app.js              — логика: подбор, чат, сказки, кабинет, отчёты
games-db.js         — база игр, часть 1
games-extra.js      — база игр, часть 2 (основная)
games-patch.js      — точечные правки базы
cards/              — карточки-подсказки к играм
.nojekyll           — чтобы GitHub Pages отдавал файлы как есть
```

## ℹ️ Примечание

Сайт автономен: база игр, подбор, дневник и отчёты считаются прямо в браузере.
Сказки озвучивает голос браузера, картинки (аватарка, супер-герой) рисуются
на устройстве. Все данные профиля хранятся только у посетителя сайта.
